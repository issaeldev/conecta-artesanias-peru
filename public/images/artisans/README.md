# Fotos de artesanos

Retratos que acompañan cada perfil de "Conoce a los artesanos". Nombre del archivo = id del taller.
Formato recomendado: vertical o cuadrado, mínimo 1200 px de ancho, con la cara y las manos trabajando. Si falta un archivo, la tarjeta
muestra un fondo de color con las iniciales.

## Fotos actuales (prototipo)

prototipo. Las personas fotografiadas no son los artesanos de las historias: antes de publicar,
reemplazarlas por las fotos reales de cada taller.
